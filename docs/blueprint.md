# **App Name**: GOplanAI 랜딩 페이지

## Core Features:

- 지속적인 네비게이션: 홈, 기능 소개, 사용 가이드, 템플릿 보기, 로그인/내 문서 링크를 포함하는 고정된 상단 메뉴. 스크롤 시 축소됩니다.
- 대화형 히어로 섹션: 키워드 입력 UI와 PDF 업로드를 위한 드래그 앤 드롭 영역이 있는 히어로 섹션.
- AI 계획 미리보기: AI가 생성한 사업 계획서의 실시간 미리보기를 표시하고, AI 툴이 입력을 처리함에 따라 업데이트됩니다. 계획서를 카드/문서 스타일로 보여줍니다. 이 기능은 도구를 사용하여 정보를 통합할지 여부를 결정합니다.
- 동적 메뉴 애니메이션: 메뉴 호버 효과(색상 변경, 하단 테두리) 및 스크롤 기반 효과(배경 변경, 그림자, 패딩 감소)를 구현합니다.
- 모바일 최적화: 모바일 메뉴(햄버거 버튼과 슬라이드 패널), 히어로 요소 쌓기, 동적 글꼴 크기 조정을 포함하여 완전한 반응성을 보장합니다.
- 클릭 유도문안 영역: 사용자에게 문서를 업로드하고 시작하라는 메시지를 표시하는 하단의 CTA 섹션.

## Style Guidelines:

- 글꼴: 기본은 'Inter'(산세리프), 한국어 문자의 대체 글꼴은 'Noto Sans KR'입니다.
- 글꼴 크기: 16px(본문), 24-40px(제목); 줄 높이: 1.5.
- 기본 색상: 기본 버튼 및 강조 표시에 Indigo-600(#4F46E5).
- 액센트 색상: 보조 강조 표시에 Cyan-400(#22D3EE).
- 텍스트 색상: 기본 텍스트에 진한 회색(#111827); 지원 텍스트에 연한 회색(#6B7280) 하위 텍스트 색상.
- 배경 색상: 페이지 배경에 매우 밝은 회색(#F9FAFB).
- 둥근 버튼(rounded-xl)과 부드러운 그림자(drop-shadow-md, shadow-lg).
- 히어로 섹션 및 기타 관련 섹션의 이미지는 picsum.photos에서 가져옵니다.
